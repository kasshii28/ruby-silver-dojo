# Ruby Silver 公式模擬問題の取り込みと修正点

`src/data/ruby-silver/q_official.yml` は、Ruby Association が公開している Silver version 3 のサンプル問題をもとにしています。

- 出典: <https://github.com/ruby-association/prep-test/blob/version3/silver_ja.md>（解答: `silver_answers_ja.md`）
- 取り込んだ版: `version3` ブランチ commit `bcbfe4425a7d575e8afb62458e5b98f7592663c9`
- 出典リポジトリには LICENSE がないため、問題文・選択肢は出典を明記して収録し、**解説はこのサイトで書き下ろしています**（公式解説の文章は転載していません）。

## 検証結果

全50問のコードを Ruby 3.3.6 で実行し（`npm run verify`）、**公式の正解はすべて実行結果と一致しました**。正解の記号が誤っている問題はありません。
誤りは問題文・選択肢の表記と、公式解説の文章にありました。

| 問題 | 公式版の誤り | 修正 |
|---|---|---|
| Q3 | 選択肢の記号が (a)(b)(c)(e) で (d) が抜けている | 4択として収録（記号はサイト側で A〜D を振り直し） |

| Q45 | 選択する数（1つ選択）が書かれていない | 「(1つ選択)」を追加 |

## 公式解説（silver_answers_ja.md）の誤り

このサイトの解説は書き下ろしなので、以下は参考情報です。

| 解答 | 誤り |

| A1 | 「オブェクト」→「オブジェクト」 |
| A5 | `Strign#%` → `String#%` |
| A10, A11 | 「1文字のも文字列」→「1文字の文字列」 |
| A21 | 「配列が変更が変更される」→「配列が変更される」 |
| A25 | 英語の原文 "Another approach is to use a range, …" が訳文の前に残っている |
| A33 | 「補足され」→「捕捉され」 |

| A38 | `@var = apple"` → `@var = "apple"`（引用符の欠落） |
| A42 | 「自分は作成したクラス」→「自分で作成したクラス」 |

## 補足

- Q11 の `{"c"=>2, "o"=>2, "a"=>1}` は Ruby 3.1〜3.3 の表示形式です。Ruby 3.4 以降は `{"c" => 2, "o" => 2, "a" => 1}` と表示されます（解説に注記）。
- 公式模擬問題は id 241〜290 です。ランダム出題の「模擬試験」「ミニテスト」「全問チャレンジ」「分野別」には混ぜず、ホームの「公式模擬問題」から番号順またはランダムで解けます。
