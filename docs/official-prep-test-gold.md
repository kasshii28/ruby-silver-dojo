# Ruby Gold 公式模擬問題の取り込みと修正点

`src/data/ruby-gold/g_official.yml` は、Ruby Association が公開している Gold version 3 のサンプル問題をもとにしています。

- 出典: <https://github.com/ruby-association/prep-test/blob/version3/gold_ja.md>（解答: `gold_answers_ja.md`）
- 取り込んだ版: `version3` ブランチ commit `bcbfe4425a7d575e8afb62458e5b98f7592663c9`
- 出典リポジトリには LICENSE がないため、問題文・選択肢は出典を明記して収録し、**解説はこのサイトで書き下ろしています**（公式解説の文章は転載していません）。

## 検証結果

全50問のコードを Ruby 3.3.6 で実行し（`npm run verify`）、**公式の正解はすべて実行結果と一致しました**。正解の記号が誤っている問題はありません。
誤りは問題文・選択肢の表記と、公式解説の文章にありました。

## 問題文・選択肢の修正（サイトに反映済み）

| 問題 | 公式版の誤り | 修正 |
|---|---|---|
| Q4 | 選択する数が「(複数選択)」で、正解の数（2つ）が分からない | 「(2つ選択)」に変更 |
| Q21 | 選択する数が書かれていない | 「(1つ選択)」を追加 |
| Q24 | 選択する数が書かれていない。選択肢 A・B の `p` の出力に `""` がない（`apple` → 実際は `"apple"`） | 「(1つ選択)」を追加し、出力を `"apple"` / `"banana"` に修正（正解は D のまま） |
| Q40 | 選択肢 D「`Hello World!`を例外を発生する」 | 「例外を発生する」に修正 |
| Q48 | 実行結果の `+09:00` が実行環境のタイムゾーンに依存する | 「タイムゾーンは日本時間（JST）とします」を問題文に追加 |
| Q8, Q9, Q22, Q26, Q39 | 問題番号の後ろが `.` ではなく `:`（表記の揺れ） | サイトでは番号を独自に表示するため影響なし |

## 公式解説（gold_answers_ja.md）の誤り

このサイトの解説は書き下ろしなので、以下は参考情報です。

| 解答 | 誤り |
|---|---|
| A5 | Ruby 3.2 以降は無名の `*` で引数を転送できるため、(A) は文法エラーではなく実行時の `TypeError` になる（3.1 では文法エラー）。解説では触れていない |
| A9 | 「`Proc`オブジェプト」→「`Proc`オブジェクト」 |
| A10 | 「しがたって」→「したがって」 |
| A16 | 冒頭の「補足説明です。」が文として不完全 |
| A38 | `Indentity` → `Identity` |
| A40 | `moudle_function` → `module_function` |
| A41 | 「クラスメソッドして使用できます」→「クラスメソッドとして使用できます」 |
| A46 | 英語の原文 "Each of these methods rely on …" が訳文の前に残っている |

## 補足

- 公式模擬問題は Gold の id 93〜142 です。ランダム出題の「模擬試験」「ミニテスト」「全問チャレンジ」「分野別」には混ぜず、Gold のホームの「公式模擬問題」から番号順またはランダムで解けます。
